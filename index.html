stack-orrery

Application architecture you can run, inspect, and understand.

A mechanical model of a web stack on concentric orbital rings — not a static diagram or a probability simulator. Addressable client browsers on the outer orbit send slim HTTP requests over two-number mini-IPs through routing, load-balancing, web-server, and cache-aside rings while you trace every hop or put the stack under load.

How the Orrery Works

Trace 1 Request Hop-by-Hop

Pick any browser on the outer ring, choose GET or POST, and step one hop at a time as your request crosses the network, round-robins at the load balancer, checks the cache, and renders in the viewport.

Watch Queues & TTL Under Load

Dial up to 50 simulated browsers on a seeded tick clock. Watch visible FIFO queues climb when arrivals exceed service rate, and see shared cache hits double warm capacity until TTL expiry triggers a miss wave.

Inspect Real Code & Live State

Click any component node on the pannable, zoomable orbital plane to read its working JavaScript implementation side-by-side with its live internal JSON state and wire journey log.
